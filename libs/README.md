# Local libraries

Iron Tanks does not require a locally staged BuildCraft jar. Forge/NeoForge BCCE dependencies resolve from Modrinth Maven; Fabric 26.3 resolves the exact 8.0.30 JAR from BCCE GitHub Releases, verified by SHA-256.

This directory is intentionally kept only as a placeholder for developer-only local libraries that may be needed in the future; production BuildCraft dependencies must not be placed here.
